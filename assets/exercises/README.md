# Как подключить реальное фото/анимацию упражнения

Сейчас вместо фото показывается нарисованная линейная пиктограмма (своего рисования,
см. [js/animations.js](../../js/animations.js)) — либо, у части упражнений, настоящее фото.

Чтобы заменить пиктограмму на фото/gif/видео:

1. Положите файл `.jpg`, `.gif`, `.mp4` или `.webm` в эту папку (`assets/exercises/`).
   Например: `chest-bench-press.jpg`.
2. Откройте [js/data/exercises.js](../../js/data/exercises.js) и у нужного упражнения
   пропишите путь в поле `mediaSrc`:

   ```js
   { id: "chest-bench-press", ..., mediaSrc: "assets/exercises/chest-bench-press.jpg" }
   ```

3. Сохраните файл — пиктограмма автоматически заменится на ваше фото/видео везде
   (в карточке дня, в плане и в библиотеке).

Короткие gif/видео (2–4 секунды, зацикленные) и сжатые фото (до ~100–150 КБ) весят
меньше и подходят лучше — они полностью попадают в офлайн-кэш приложения.

**Важно про авторские права:** используйте только свои фото/видео или материалы с
открытой лицензией (CC0, CC BY — с указанием автора). Не берите картинки из поиска
Google или платных стоковых баз фитнес-анимаций без проверки лицензии.
