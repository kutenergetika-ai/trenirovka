# Как подключить реальные анимации упражнений

Сейчас вместо анимации показывается простая цветная заглушка (плейсхолдер).

Чтобы заменить её на настоящую анимацию конкретного упражнения:

1. Положите файл `.gif`, `.mp4` или `.webm` в эту папку (`assets/exercises/`).
   Например: `chest-bench-press.gif`.
2. Откройте [js/data/exercises.js](../../js/data/exercises.js) и у нужного упражнения
   пропишите путь в поле `mediaSrc`:

   ```js
   { id: "chest-bench-press", ..., mediaSrc: "assets/exercises/chest-bench-press.gif" }
   ```

3. Сохраните файл — плейсхолдер автоматически заменится на вашу анимацию везде
   (в карточке дня, в плане и в библиотеке).

Короткие gif/видео (2–4 секунды, зацикленные) весят меньше и подходят лучше — они
полностью попадают в офлайн-кэш приложения.
