# Тренировка

Офлайн-приложение для тренировок (PWA). Устанавливается на домашний экран iPhone через
Safari и дальше работает без интернета.

## Структура

```
index.html              страница приложения
manifest.json           PWA-манифест (иконка, имя, цвета)
service-worker.js       офлайн-кэш (кэширует всё при первом открытии)
css/styles.css          стили
js/app.js               роутер + нижняя навигация + установка SW
js/db.js                хранилище (localStorage): план, факт по дням, настройки
js/data/exercises.js    библиотека упражнений (редактируйте/дополняйте здесь)
js/animations.js        анимации-пиктограммы упражнений (SVG, свой рисунок)
js/placeholder.js       выбирает: своя анимация или реальный gif/видео (mediaSrc)
js/modal.js             модалки: карточка упражнения, выбор упражнения, выбор дней
js/views/today.js       экран «Сегодня» — факт тренировки на сегодня
js/views/planner.js     экран «План» — шаблон на дни недели (повторяется каждую неделю)
js/views/library.js     экран «Библиотека» — все упражнения, поиск/фильтр
js/views/history.js     экран «История» — прошлые тренировки
assets/icons/           иконки приложения (сгенерированы)
assets/exercises/       сюда кладутся реальные gif/видео упражнений (см. README там)
```

## Как это устроено

- **План недели** — шаблон: какие упражнения в какие дни недели (Пн–Вс), повторяется
  каждую неделю.
- **Сегодня** — создаётся «снимок» плана на конкретную дату. Можно менять подходы/
  повторы/вес и даже заменить упражнение — это не затронет сам шаблон плана. Кнопка
  «Сбросить к плану дня» возвращает сегодняшнюю тренировку к шаблону.
- Все данные хранятся локально в localStorage телефона — ничего не уходит в интернет.

## Запуск локально (для разработки на компьютере)

```
python -m http.server 8765
```

Открыть `http://localhost:8765` в браузере.

## Как установить на iPhone и проверить офлайн-режим

Service worker (а значит и офлайн-режим) регистрируется только на HTTPS-адресе —
открыть `index.html` напрямую файлом или через IP в локальной сети Safari не даст
полноценный офлайн-режим. Поэтому для реальной проверки на iPhone нужно один раз
выложить файлы на бесплатный HTTPS-хостинг:

1. Самый быстрый способ — [Netlify Drop](https://app.netlify.com/drop): перетащить
   папку проекта в браузере, сразу получить ссылку вида `https://...netlify.app`.
2. Либо GitHub Pages, если у вас уже есть аккаунт GitHub — могу помочь настроить.

Дальше на iPhone:
1. Открыть полученную ссылку в **Safari**.
2. Нажать «Поделиться» → **«На экран «Домой»»**.
3. Открывать приложение с домашнего экрана — после первого открытия оно полностью
   работает без интернета (всё закэшировано).

## Как добавить реальные анимации упражнений

Сейчас у каждого упражнения — нарисованная с нуля линейная анимация-пиктограмма
(жим, тяга, присед и т.д.), чтобы не нарушать чужие авторские права. Как заменить
на настоящее видео/gif — см. [assets/exercises/README.md](assets/exercises/README.md).

## Как добавить/изменить упражнения

Откройте [js/data/exercises.js](js/data/exercises.js) — каждое упражнение это один
объект в массиве `EXERCISES`. Поле `animation` задаёт тип анимации-пиктограммы:
`press | pull | elbow | squat | hinge | lunge | raise | core_move | core_hold | pushup | cardio`.
